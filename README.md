# nay4n

Personal portfolio website of Nayan.

Live site: [nayanba.com](https://nayanba.vercel.app/)

This project showcases my work, projects, experiments, and ongoing journey in frontend engineering, product-focused web development, and AI-powered tools.

Built with:

- Next.js
- React
- Tailwind CSS

Hosted on:

- Vercel

## Running locally

```bash
npm install
npm run dev
```
